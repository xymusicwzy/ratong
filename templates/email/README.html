仁爱通 · Supabase 邮件模板安装说明

本目录包含与当前网站认证流程配套的 HTML 邮件模板。请管理员在 Supabase 项目 Authentication → Email Templates 中逐项复制对应 HTML 内容。

模板对应关系

  • Confirm signup / 注册确认：signup-otp.html。使用 {{ .Token }}，网站页面输入 6 位 OTP。
  • Invite user / 用户邀请：invite.html。使用 {{ .ConfirmationURL }}。
  • Reset password / 密码重置：recovery.html。使用 {{ .ConfirmationURL }}。
  • Magic link / 邮箱快捷登录：magic-link.html。使用 {{ .Token }}，并在网站输入验证码。
  • Change email / 邮箱变更：change-email.html。

必须核对的项目设置

  1. 在 Authentication → URL Configuration 中将 Site URL 设置为 https://xymusicwzy.github.io/ratong/，并允许对应 Redirect URL。
  2. 在 Authentication → Providers → Email 中启用 Email OTP，并设置合适的验证码有效期和频率限制。
  3. 配置自己的 SMTP 服务及发件人邮箱。不要把 SMTP 密码、服务密钥或 service_role key 放入网站代码。
  4. 确认 Invite / Recovery / Email OTP 均能收到邮件，再用新注册邮箱完成实际测试。

Google Authenticator

OA 的“安全与邮件”页面已提供 TOTP 绑定、二维码扫描和动态码验证。管理员应为 OA 管理账号绑定验证器。验证码失效或遗失时，应由管理员按安全流程处理账号恢复。

注意

网站已提供 OTP 输入与验证代码，但 Supabase Dashboard 的邮件模板和 SMTP 发送服务属于项目 Auth 配置，不会通过 GitHub Pages HTML 自动变更。请在粘贴模板并配置 SMTP 后，再进行注册、邀请和密码重置的真实收件测试。
